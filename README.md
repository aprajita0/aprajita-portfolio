# Aprajita Srivastava Portfolio

A modern personal portfolio website built to showcase my experience in software engineering, AI/ML, backend systems, full-stack development, and research.

Live site: [aprajita-portfolio.aprajita0625.workers.dev](https://aprajita-portfolio.aprajita0625.workers.dev)

## About

This portfolio highlights my background as a Computer Science student at the City College of New York, graduating in June 2026. It includes my professional experience, technical projects, skills, education, and contact information in a clean, recruiter-friendly format.

## Features

- Responsive modern portfolio design
- Dark-themed UI with subtle motion and interactions
- About, Experience, Projects, Skills, Education, and Contact sections
- Featured technical projects with GitHub links
- Resume download support
- Smooth scrolling and polished UI effects
- Built for performance and readability
